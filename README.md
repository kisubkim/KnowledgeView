# KnowledgeView

Markdown 문서를 읽어 더 상세하게 정리한 **HTML 페이지(문서당 HTML 파일 1개)** 로 만들고, 웹 브라우저에서 목록을 보고 열람하는 로컬 웹 앱입니다.

- 원본 MD 폴더는 **읽기만** 합니다.
- 결과 HTML은 출력 폴더(기본 `output/`) 아래 **카테고리 폴더**에 저장됩니다. 기본값은 원본 폴더 구조를 그대로 따르는 것입니다(`01_LLM_기초_이론/03_토크나이저.md` → `output/01_LLM_기초_이론/03_토크나이저.html`).
- 페이지는 CSS, JS, 그림(data URI)을 모두 안에 담은 HTML 파일 하나입니다. 렌더링 코드(mermaid, 그리고 다이어그램 글자 대비 보정 같은 공용 런타임 `kv-page.js`)는 페이지에 넣지 않고 앱이 `/assets/`로 제공합니다. 그래서 다이어그램은 앱을 통해 열어야 그림으로 보이고, 런타임을 고치면 이미 만든 페이지에도 재생성 없이 반영됩니다. 파일을 직접 열면 다이어그램이 원본 코드로 표시됩니다.
- 다이어그램을 그린 뒤 라벨마다 실제 배경색을 계산해, 글자 대비가 WCAG 4.5:1 미만이면 글자색을 진한 색이나 흰색으로 바꿉니다(원문이 `style ... fill:` 로 밝은 배경을 지정한 경우, 특히 다크 모드).

## 상세화 방식

| 방식 | 동작 |
|---|---|
| 구조화 (LLM 없음) | 원문을 템플릿으로 재구성합니다: 목차, 메타 정보 카드, 다이어그램 렌더링, 코드 하이라이트, 핵심 포인트 모음 |
| Claude Code CLI | 서버 PC의 `claude -p`(도구 비활성화)로 섹션(`##`)마다 해설·예시·비유·흔한 오해·요약을 덧붙이고, 개요·용어 사전·확인 문제를 만듭니다 |
| OpenAI 호환 | 같은 작업을 vLLM, Ollama 등 `/v1/chat/completions` 엔드포인트로 합니다. 엔드포인트는 설정에서 여러 개 추가·삭제할 수 있고, 각각 별도 방식으로 고릅니다. 추론(thinking) 모델은 엔드포인트의 "추론 강도"를 `none`으로 두면 빠르고 토큰 제한에 덜 걸립니다(Ollama gemma4에서 확인) |

LLM 모드에서는 그림이 이해를 돕는 곳(섹션당 최대 2개, 설정 가능)에 그림도 넣습니다. 먼저 Wikimedia Commons에서 재사용 가능한 라이선스(CC0, 퍼블릭 도메인, CC BY, CC BY-SA)의 이미지를 찾아 LLM이 맞는 것을 고르고, 없으면 LLM이 SVG를 그립니다. 웹 이미지는 캡션에 출처, 작성자, 라이선스를 표시합니다. 웹 검색은 서버 PC에서 인터넷이 필요하며, 백신의 TLS 검사 환경에서도 동작하도록 Windows 인증서 저장소(`truststore`)를 씁니다.

LLM 결과(섹션, 개요, 그림)는 `data/cache/`에 저장됩니다. 같은 원문, 설정, 프롬프트로 재생성하면 LLM을 다시 부르지 않습니다. 새 결과가 필요하면 생성/재생성할 때 "LLM 결과 새로 받기"를 켜세요.

LLM은 원문을 고치지 않고 `> [!DETAIL]` 같은 callout만 덧붙입니다. 결과에서 원문의 제목이나 mermaid 다이어그램이 빠지거나 응답이 원문보다 짧으면, 그 섹션은 원문을 그대로 쓰고 경고를 남깁니다. 페이지 상단의 "보강 내용 표시" 버튼으로 덧붙인 내용을 숨기면 원문만 볼 수 있습니다.

## 설치형 실행 파일 (Windows)

`dist\KnowledgeView-Setup.exe` 하나로 설치합니다(Python 설치 필요 없음, 관리자 권한 없이 현재 사용자에게 설치).

- 실행하면 설치 창이 열립니다: 설치 위치, **데이터 폴더**(설정·캐시·업로드·로그), **출력 폴더**(HTML 페이지), 원본 MD 폴더(선택), 포트, 다른 PC 접속 허용과 관리 토큰, 시작 메뉴/바탕 화면 바로가기, 로그인 시 자동 실행.
- 설치가 끝나면 브라우저가 열리고 작업 표시줄 트레이에 K 아이콘이 생깁니다(열기, 출력 폴더 열기, 데이터 폴더 열기, 종료).
- 웹 화면 오른쪽 위 **종료** 버튼(서버 PC에서 열었을 때만 보임)은 "트레이에 두기"(서버 계속 실행)와 "완전히 종료" 중 하나를 묻습니다. "다음부터 묻지 않기"를 고르면 설정의 "종료 버튼" 항목에 저장됩니다.
- **Claude Code**가 설치되어 있고 로그인되어 있을 때만(`claude auth status`) "Claude Code CLI 상세화" 방식이 나타납니다. 나중에 설치·로그인했다면 설정 화면의 "다시 확인"을 누르세요.
- **포트**는 웹 화면의 설정 > 서버에서 바꿀 수 있습니다(서버 PC에서만). 다른 프로그램이 쓰는 포트는 거부하고, 저장한 뒤 "지금 다시 시작"을 누르면 새 포트로 다시 떠서 열린 탭이 새 주소로 옮겨 갑니다. 환경 변수 `KV_PORT`가 있으면 그것이 우선합니다.
- 폴더를 바꾸려면 설치 파일을 다시 실행하거나 `KnowledgeView.exe --install`을 실행합니다(기존 값이 채워진 상태로 열림). 제거는 Windows 설정의 "앱 및 기능"에서 하며, 데이터와 페이지를 남길지 묻습니다.
- 단일 실행 파일이라 실행할 때마다 임시 폴더에 압축을 풉니다. 백신이 풀린 파일을 검사하면 첫 실행이 30초 가까이 걸릴 수 있습니다.

빌드: `powershell -ExecutionPolicy Bypass -File build.ps1` (테스트 실행 후 `dist\KnowledgeView-Setup.exe` 생성). 포함된 라이브러리의 라이선스는 `THIRD_PARTY_NOTICES.md`에 있습니다.

## 소스에서 설치와 실행 (Windows)

```bat
setup.bat      :: .venv 생성 + 의존성 설치 (Python 3.12)
start.bat      :: http://localhost:8770/  (기본 0.0.0.0 바인딩, 다른 PC에서 접속 가능)
```

환경 변수:

| 변수 | 기본값 | 설명 |
|---|---|---|
| `KV_HOST` | `0.0.0.0`(start.bat) / `127.0.0.1`(직접 실행) | 바인딩 주소 |
| `KV_PORT` | `8770` | 포트 |
| `KV_ADMIN_TOKEN` | 없음 | 설정하면 생성·삭제·설정 같은 관리 기능에 토큰이 필요합니다. 페이지 열람과 목록 조회는 토큰 없이 됩니다 |
| `KV_DATA_DIR` | `data` | 설정(`settings.json`), 업로드한 MD(`uploads/`), LLM 캐시(`cache/`), 거부된 LLM 응답(`llm_failures/`) 위치 |

다른 PC에 공개할 때는 `KV_ADMIN_TOKEN`을 설정하세요. 설정하지 않으면 접속한 누구나 서버 PC에서 Claude CLI 호출을 실행할 수 있습니다.

## 사용

1. **설정** 탭: 원본 MD 폴더(여러 개 가능), 출력 폴더, 기본 방식, Claude CLI 또는 OpenAI 호환 엔드포인트를 설정하고 "연결 확인"을 누릅니다.
2. **생성** 탭: 방식과 저장할 카테고리(원본 구조를 따르거나 지정 카테고리)를 고르고 MD 파일을 선택해 생성합니다. 다른 PC에서는 MD 파일을 끌어 놓아 올릴 수 있습니다(`data/uploads/`에 저장).
3. **작업** 탭: 진행률, 로그, 취소. 작업 큐는 메모리에만 있어서 서버를 재시작하면 사라집니다.
4. **문서** 탭: 카테고리별 목록, 검색, 열기, 재생성, 다른 카테고리로 이동, 삭제. 원본 MD가 생성 후 바뀌면 "원본 변경됨" 배지가 붙습니다.

## 그림 보기와 내보내기

- 다이어그램이나 그림을 누르면 전체 화면 뷰어가 열립니다. 휠로 확대/축소, 드래그로 이동, 더블클릭으로 2배/맞춤, 키보드 `+` `-` `0`(맞춤) `1`(실제 크기) 방향키, `Esc`로 닫기. 확대는 SVG를 다시 그리므로 글자가 흐려지지 않습니다. 터치 화면에서는 두 손가락으로 확대합니다.
- 뷰어의 "SVG 저장"/"PNG 저장"으로 지금 보고 있는 다이어그램이나 그림을 파일로 받습니다(PNG는 고해상도로 변환, 웹 그림 PNG는 원본 그대로).
- 페이지 상단과 문서 카드의 "그림 내보내기"는 페이지의 모든 그림(`figures/`, PNG/SVG), mermaid 원본(`diagrams/*.mmd`), 캡션·출처·라이선스 목록(`그림_목록.md`)을 ZIP 하나로 받습니다.

## 이전 버전

페이지를 덮어쓰면(재생성, 같은 카테고리에 다시 생성) 기존 파일은 새 페이지가 완성된 뒤 `output/.history/<카테고리>/<문서명>/<시각>.html`로 옮겨집니다. 생성이 실패하거나 취소되면 기존 페이지는 그대로입니다. 문서 카드의 "이전 버전"에서 열기, 복원(현재 페이지는 이력으로), 삭제를 할 수 있습니다. 페이지당 보관 개수는 설정의 "보관할 이전 버전 수"(기본 20, 0이면 모두)입니다. 페이지를 이동하면 이력도 함께 옮겨지고, 페이지나 카테고리를 삭제하면 이력도 함께 삭제됩니다.
